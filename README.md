# 📋 Kanban Board

Многодосочная канбан-доска на **Python 3.10+** и **PyQt6** с drag & drop, автосохранением и тёмной темой в стиле Catppuccin.

## 📖 О проекте

**Kanban Board** — десктопное приложение для управления задачами по методологии Kanban. Поддерживает несколько независимых досок в виде вкладок, перетаскивание карточек между колонками и автоматическое сохранение в JSON.

Проект демонстрирует работу с:
- виджетами и компоновками PyQt6 (`QLayout`, `QTabWidget`, `QScrollArea`);
- drag & drop (`QDrag`, `QMimeData`, `dropEvent`);
- сигналами и слотами;
- кастомными стилями через QSS;
- сериализацией данных в JSON.

---

## ✨ Возможности

- 🗂 **Несколько досок** — каждая в отдельной вкладке
- ➕ Создание, переименование и закрытие досок (двойной клик / ПКМ по вкладке)
- 🖱 **Drag & drop** карточек между колонками
- 📝 4 колонки по умолчанию: **To Do**, **In Progress**, **Review**, **Done**
- ✏ Создание и редактирование задач (название + описание)
- 🗑 Удаление задач (крестик или ПКМ → «Удалить»)
- 🔢 Счётчик задач в каждой колонке
- 💾 **Автосохранение** в `boards/<имя_доски>.json` после каждого действия
- 🔄 Автозагрузка всех досок из папки `boards/` при старте
- 🎨 Тёмная тема в стиле Catppuccin Mocha
- 🖱 Кастомный полупрозрачный pixmap при перетаскивании карточки
- 📦 Демо-данные при первом запуске

## ⚙️ Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/username/kanban-board.git
cd kanban-board
```

### 2. Создание виртуального окружения

**Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Или вручную:
```bash
pip install PyQt6
```

## 🚀 Запуск

Из корневой папки проекта:

```bash
python kanban.py
```

При первом запуске автоматически создастся папка `boards/` с демо-доской «Моя доска».

## 🎮 Использование

| Действие | Как |
|----------|-----|
| **Создать доску** | Кнопка **«＋ Новая доска»** вверху или ПКМ по вкладкам |

| **Поменять порядок вкладок** | Зажать и тащить вкладку |

| **Перетащить задачу** | Зажать ЛКМ на карточке и тянуть в другую колонку |
| **Редактировать задачу** | ПКМ по карточке → «Редактировать» |
| **Удалить задачу** | Крестик **✕** на карточке или ПКМ → «Удалить» |
| **Очистить доску** | Кнопка «🗑 Очистить доску» |
| **Сбросить к демо** | Кнопка «🔄 Сброс» |

## 🏗 Архитектура

Приложение построено на трёх ключевых классах:

| Класс | Назначение |
|-------|------------|
| `TaskCard` | Карточка задачи. Реализует drag & drop, контекстное меню, сигналы `delete_requested` / `edit_requested` |
| `Column` | Колонка доски. Принимает `dropEvent`, управляет карточками, ведёт счётчик |
| `BoardWidget` | Одна доска (вкладка). Содержит 4 колонки, отвечает за загрузку/сохранение в JSON |
| `KanbanWindow` | Главное окно с `QTabWidget`. Управляет досками: создание, переименование, закрытие |
| `TaskDialog` | Модальный диалог создания/редактирования задачи |

### Принципы

- **Разделение ответственности** — `Column` не знает о других колонках, `BoardWidget` не знает о вкладках, `KanbanWindow` не знает о карточках.
- **Сигналы вместо прямых вызовов** — карточка сообщает о желании удалиться через сигнал, а не напрямую удаляет себя.
- **Автосохранение через `notify_change()`** — любое изменение поднимается до `BoardWidget.save_data()`.
- **PEP 8** — осмысленные имена, docstring'и, длина строк ≤ 88 символов.

## 💾 Формат данных

Каждая доска хранится в отдельном JSON-файле `boards/<имя>.json`:

```json
{
  "todo": [
    {
      "title": "Сделать канбан-доску",
      "description": "PyQt6 + drag & drop"
    }
  ],
  "in_progress": [
    {
      "title": "Дизайн интерфейса",
      "description": "Тёмная тема в стиле Catppuccin"
    }
  ],
  "review": [],
  "done": []
}
```

Имя файла получается из имени доски через `safe_filename()` (нижний регистр, пробелы → `_`, удаление спецсимволов).

## 📦 Сборка в EXE

### Установка PyInstaller

```bash
pip install pyinstaller
```

### Сборка одним файлом

```bash
pyinstaller --onefile --windowed --name KanbanBoard kanban.py
```

Готовый `KanbanBoard.exe` появится в папке `dist/`.

### С иконкой

```bash
pyinstaller --onefile --windowed --icon=icon.ico --name KanbanBoard kanban.py
```

> 💡 Для сборки под Windows запускай PyInstaller в Windows. Для Linux/macOS используй соответствующую ОС.
